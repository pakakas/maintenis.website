GitHub Spesifikasi

Apa itu Sapdain?

Bahasa Sapdain adalah bahasa pemrograman yang lahir dari ekosistem Maintenis (Mei 2026). Dirancang bukan hanya untuk manusia, tapi juga untuk AI — dengan fitur linguistik Indonesia dan Sunda yang membuatnya mudah dipahami sekaligus efisien untuk diproses oleh model bahasa.

AI-Native

Dirancang dari awal untuk AI. Fitur ber/nya linguistik membantu LLM memahami konteks tanpa prompt tambahan.

Indonesia + Sunda

Menggabungkan sintaksis bahasa Indonesia dan struktur bahasa Sunda. Bukan terjemahan — ini bahasa baru.

Agent IR Integration

Punya layer ADN-Sapdain yang bisa encode output ke MarkZero format — Agent IR yang dioptimalkan untuk token efficiency.

Compiler Zig

Compiler ditulis dalam Zig untuk performa tinggi. Saat ini masih dalam tahap draft/development.

Mengapa AI-Native?

Bahasa pemrograman lokal sudah ada sebelum Sapdain — Naskah, BAIK, Jaksel, Sundalang, dan lainnya. Tapi Sapdain lahir dengan 2 perbedaan fundamental:

1. AI-Native dari Awal

Sapdain dirancang untuk AI sejak hari pertama, bukan sebagai bahasa manusia yang kemudian diadaptasi untuk AI. Fitur linguistik ber/nya dan integrasi dengan ADN encoder menjadikannya unik.

2. Agent IR Layer

Sapdain punya encoder ADN-Sapdain yang bisa mengubah output program menjadi MarkZero format — data format yang 26-71% lebih efisien dari JSON untuk AI. Ini tidak dimiliki bahasa lokal lainnya.

ADN-Sapdain Encoder

Integrasi dengan ADN (Agent Data Notation) memungkinkan output program Sapdain langsung di-encode ke format MarkZero — Agent IR yang dioptimalkan untuk token efficiency.

ADN Encoder

Sapdain punya encoder khusus yang menghubungkan bahasa dengan data layer. Output program bisa langsung menjadi structured data untuk AI.

MarkZero Output

Encoder menghasilkan MarkZero format — 26-71% lebih efisien dari JSON di 9 model LLM yang sudah diuji secara live.

1-Token Markers

MarkZero menggunakan marker yang masing-masing hanya 1 token di semua model. Validated empirically di MiMo, DeepSeek, Grok, GLM, Qwen, dan lainnya.

CLAI Pipeline

Output encoder bisa langsung masuk ke CLAI pipeline: transport(input) → entity → filter → transport(output)
